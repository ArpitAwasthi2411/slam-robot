    How do I get the phone and robot on the same network?

    Robot Wi‑Fi (simplest). Join the Wi‑Fi called SLAM-Robot. Pathik finds the robot at 10.42.0.1.

    Your phone's hotspot. Turn the hotspot on, let the robot join it, then tap Find robot. Pathik scans the hotspot network.

    Far away (another lab, another floor). Put a phone with mobile data on the robot as its hotspot, and install Tailscale on the Pi and on this phone. Then type slam-robot (or its 100.x address) below. The robot keeps working on its own if the link drops.

    Robot not found? Check that robot_up is running on the Pi and that the phone isn't on mobile data only.
